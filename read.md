# 🇮🇳 Makkal Kural — மக்கள் குரல்

### AI-Powered Civic Complaint Platform

Makkal Kural is a civic engagement platform that allows Tamil Nadu citizens to report public issues such as road damage, water problems, garbage, electricity, drainage, streetlights, and other civic grievances. Users can submit complaints, select their location, connect with verified representatives, and track complaint status.

## 🚀 Live Demo

👉 **[Visit Makkal Kural](https://makkal-kural-smoky.vercel.app/)**

## ✨ Features

* 📝 Submit civic complaints
* 📍 Location-based complaint routing
* 🏛️ Verified government/official directory
* 📊 Complaint tracking
* 📷 Upload supporting images
* 🔎 Search and track complaint status
* 🌐 Tamil & English support
* 🔐 Citizen and admin portals

## 🛠️ Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Supabase
* Vercel

## 🎯 Goal

To make civic issue reporting faster, transparent, and accessible by connecting citizens with the appropriate authorities.
